Are you still using `moment.js` in 2026? Do you really need `lodash` just to filter an array? 

**Pkg Roast** is an interactive, highly judgmental CLI that analyzes your local `package.json` and uses heuristic AI typing animations to ruthlessly mock your tech stack choices.

## ✨ Features

- **🔥 Brutal Honesty:** Analyzes both `dependencies` and `devDependencies` and matches them against dozens of snarky roasting heuristics.
- **🤖 Typewriter Animations:** Simulates a sentient AI slowly typing out its profound disappointment in your architecture.
- **🎨 Premium UI:** Custom ASCII art, color-coded output, and a polished terminal experience.

## 🚀 Installation

Run it instantly anywhere without installing:

```bash
npx pkg-roast
```

Or install it globally:

```bash
npm install -g pkg-roast
```

## 🎮 Usage

Navigate to any directory with a `package.json` and run:

```bash
pkg-roast
```

Sit back and prepare to be judged.
